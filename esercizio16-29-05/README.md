# Esercizio 16
Chiedi il saldo attuale e l'importo da prelevare. Prima verifica se l'importo è positivo. Se lo è, verifica se il saldo è sufficiente. Se sì, stampa "Prelievo effettuato" e il nuovo saldo, altrimenti stampa "Saldo insufficiente".

## Ragionamento

Chiedere all'utente il suo saldo e l'importo da prelevare.
- Verifichiamo se l'importo è positivo.
  - Se l'importo dato è positivo 
    - Altrimenti stampa importo negativo
  - Verifichiamo se il saldo è sufficiente
    - Se è sufficiente stampa Prelievo effettuato e il nuovo saldo
- Altrimenti stampa Saldo insufficiente.
